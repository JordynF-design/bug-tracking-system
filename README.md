# Bug Tracking System

A web-based bug tracking application built with Python, Flask, SQLite, HTML, and CSS. This project helps users report, organize, track, and manage software bugs.

## Features

- **Dashboard:** View total bugs, open bugs, in-progress bugs, and resolved bugs.
- **Bug Reporting:** Submit new bug reports with a title, description, priority, and assigned developer.
- **Bug Management:** Edit and delete existing bug reports.
- **Status Tracking:** Update bug statuses as work progresses.
- **Search and Filtering:** Find bugs by title, priority, and status.
- **Sorting:** Organize reported bugs for easier management.
- **Flash Messages:** Receive confirmation messages after successful actions.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git and GitHub
